# Stop Watch

A simple and responsive stopwatch web application built using React. This app allows users to accurately track elapsed time with features like Start, Pause, and Reset. Designed with a clean and user-friendly interface, it works smoothly across desktop and mobile devices.

## Features

- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Real-time time tracking
- Responsive design
- Simple and clean UI

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
