# Stop Watch

A simple and responsive stopwatch web application built using React. This app allows users to accurately track elapsed time with features like Start, Pause, and Reset.

## Features

- Start stopwatch
- Pause stopwatch
- Reset stopwatch
- Responsive design
- Simple and clean UI

## Technologies Used

- JavaScript
- HTML5
- CSS3
